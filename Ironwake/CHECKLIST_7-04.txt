--- SYSTEM FIXES -----------------------------------------------
[ ] POST-COMBAT HP BAR BUG: FOUND + FIXED, and it was NOT just
    visual. Putting a level-up point into CON overwrote your
    max HP with the BARE stat value - wiping gear +HP, Thick
    Skin and boon/curse mults - and the clamped HP was saved as
    your carried run HP (real HP loss). Now applies only the
    CON delta. This fired exactly at the extract/descend prompt.
[ ] Unequip HP rule: VERIFIED already correct in the engine -
    run HP is stored as a number and only clamped when above
    the new max (20/40 minus a +10HP piece = 20/30). Equipping
    never raises current HP, so no heal-cheat exists. Fixed one
    display spot (Stats tab) that showed unclamped HP.
[ ] Pet "Luna didn't evolve": wiring is correct - the catch is
    the pet must be your ACTIVE COMPANION on that run (and the
    run must end in extract/clear, not death). The READY text
    now says so + tells you where to equip it, and if a ready
    pet stayed home you get an explicit notice on hub return.
    -> Try: equip Luna at dungeon gate > Companion, do a run.
[ ] Rest sites scale: 15 + 4/Awakening tier + 5% of max HP
    (A4 @ 200 HP = ~41). Room text + node preview updated.
[ ] Enemy pack sizes: awakening-shifted. A0-1 mostly 2-3
    (4-pack ~10%), A2-3 4-pack ~25%, A4-5 4-pack ~40% with
    occasional 5-PACKS. Deeper floors still nudge larger.
[ ] Gold HUD on runs: "Gold: 812g (+130g this run - at risk)"
