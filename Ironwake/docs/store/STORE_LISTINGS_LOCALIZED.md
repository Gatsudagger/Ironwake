# Ironwake — Localized Store Listings (Steam + Google Play)

Paste-ready translated listing copy. Source of truth for English = STEAM_PAGE_KIT.md
(Steam) + PLAY_STORE_KIT.md (Play). Drafted 2026-07-17.

**IMPORTANT — read first:**
- These are **store-LISTING** translations only. **The game itself is still English-only
  in-game.** Localizing a listing does NOT require the game to support that language, and
  it's a cheap, no-rebuild discoverability win on both stores. But be honest about it (see
  §0) so you don't earn "not in my language" reviews.
- Translations here are **developer/AI-drafted marketing copy**. That's standard practice
  for store listings, but a **native-speaker polish pass before publish is recommended**,
  especially German (register/compounds). Marketing copy ≠ the in-game RPG flavor we agreed
  needs human care.
- `Ironwake` is a proper noun — never translate the title. Mechanic names (Awakening,
  Exposed) are translated here for readability; in-game they appear in English.
- **Play short description is a HARD 80-char limit.** Counts below are approximate — verify
  on paste. Steam short desc limit is ~300.

## §0. Honesty settings (do this so localized listings don't backfire)

**Steam** — Store page descriptions localize independently into ~29 languages. BUT the
**"Supported Languages" table (Interface / Full Audio / Subtitles) must stay English-only**
until the in-game loc() work ships. Localizing the *description* is fine and expected;
ticking Interface/Subtitles for a language you don't have in-game is what triggers refund
complaints. Upgrade those flags later when the game is actually localized.

**Play** — Add per-language listings under "Store listing → Manage translations." The
listing language and the app's in-game language are separate. **Recommended:** add one line
near the top of each non-English full description, e.g.:
- ES: *(El juego se juega actualmente en inglés.)*
- DE: *(Das Spiel wird derzeit auf Englisch gespielt.)*
- PT-BR: *(O jogo é jogado atualmente em inglês.)*

This one line converts "deep reach" from a review risk into a clean discoverability play.

## §9. Going deeper on mobile reach (recommendation + what each store needs)

**Principle for an English-only game:** localize the LISTING broadly (near-free discovery),
keep the in-game "supported languages" honest, add the "played in English" line. When the
loc() in-game work eventually ships for a language, upgrade its supported-languages flags.

**Priority order to add next** (highest download ROI first; ✔ = Latin-script, our fonts
already cover it if we ever localize the game):

| Tier | Play (mobile) focus | Steam focus | Notes |
|---|---|---|---|
| Done | ES ✔, DE ✔, PT-BR ✔ | same | this doc |
| Next 1 | French ✔, Italian ✔, Turkish ✔, Indonesian ✔ | French ✔, Russian, Simplified Chinese | ID + TR are massive mobile markets; RU + ZH-CN are top-3 Steam audiences |
| Next 2 | Russian, Vietnamese ✔, Thai | Japanese, Korean, Polish ✔ | non-Latin listings render fine on both stores |
| Optional | Japanese, Korean, Hindi | Ukrainian, Spanish-Spain split | Hindi: India Play is huge but English-tolerant; lower urgency |

**Store mechanics recap:**
- **Steam:** Steamworks → Store Page → per-language localization; supports ~29 store
  languages. Description-only localization needs no build. Keep Interface/Subtitles = English.
- **Play:** Console → Main store listing → Manage translations; supports ~80+ languages.
  Per-language title (keep "Ironwake"), short (80), full (4000), and optionally localized
  screenshots (skip — ours are English UI, fine to reuse). Add the "played in English" line.
- **Graphics:** no per-language art needed now (game UI is English; screenshots stay English).
  Only revisit localized screenshots if/when the game UI is localized.

**Biggest single lever for *mobile* specifically:** Brazil (PT-BR ✔ done), Indonesia (ID),
Turkey (TR), and Latin-America Spanish (ES ✔ done) are the download giants where a localized
listing moves the needle most. That points to **ID + TR + FR + IT** as the highest-value
next batch for Play.
